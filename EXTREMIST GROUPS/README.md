# Extremist Groups — Documentation Archive

This folder contains open-source intelligence (OSINT) documentation on
organized harassment networks, extremist collectives, and coordinated
abuse operations.

The purpose of this archive is public documentation. Groups cataloged
here have been identified through publicly available evidence —
their own posts, their own claims of responsibility, platform
moderation records, reporting by established researchers, and
verified screenshots with timestamps.

## Documentation Standards

Every entry in this folder is held to the following standard:

1. **Verifiable claims only.** Any factual assertion about a group or
   individual must be backed by a linked, publicly accessible source.

2. **No unverified accusations.** Allegations are labeled as
   "alleged" unless they are supported by direct evidence or
   acknowledgment from the party themselves.

3. **No private individuals.** Only public-facing handles, group
   names, and organizational identities are documented. Personal
   identifying information about private individuals is never
   included, even when it is publicly available elsewhere.

4. **Evidence with timestamps.** Screenshots and archives include
   capture dates and, where possible, links to archived versions
   (Wayback Machine, archive.today, or independent mirrors).

5. **Separation of verified and unverified.** Each entry contains a
   clear "Verified" section and a clearly labeled "Alleged" section.

6. **No doxing.** This archive documents group activity and public
   statements. It does not publish home addresses, employer
   information, family details, or any material whose sole purpose
   is to enable harassment of a private individual.

## What This Archive Is Not

- It is not a call to action.
- It is not a target list.
- It is not a place to publish unverified claims against private
  people.
- It is not affiliated with any law enforcement or government agency.

Where criminal activity is documented, the appropriate reporting
channels are: NCMEC (cybertip.org), the FBI IC3 (ic3.gov), and the
relevant platform's Trust & Safety team.

## Folder Structure

Each group is documented in its own subfolder and includes:

- `README.md` — overview, aliases, tactics, status
- `evidence/` — archived screenshots, links, and preserved posts
- `sources.md` — external reporting and references
- `timeline.md` — dated sequence of documented activity (where applicable)

## Status Labels

| Label | Meaning |
|---|---|
| **Active** | Documented activity within the last 30 days |
| **Fractured** | Reduced activity; leadership or structure disrupted |
| **Inactive** | No documented activity in 6+ months |
| **Unknown** | Insufficient public data to assess current status |

## Contributing

Submissions are reviewed against the standards above. Unverified
claims, personal information about private individuals, and calls to
action are rejected on submission.
